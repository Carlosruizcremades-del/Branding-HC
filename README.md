Quiero construir un panel de control web para mi empresa familiar, Helados Cremades, una heladería artesanal de Málaga fundada en 1970.

Quiero que desarrolles una primera versión funcional, visualmente elegante y fácil de utilizar, con los colores azul oscuro, crema y detalles dorados de nuestra marca.

El panel debe incluir:

1. **Resumen general:** ventas del día, ventas del mes, gastos, beneficio estimado y comparación entre establecimientos.
2. **Establecimientos:** El Palo y Pedregalejo, con sus datos separados.
3. **Ventas:** registro por fecha, establecimiento y método de pago.
4. **Gastos:** categorías, proveedores, fecha e importe.
5. **Productos:** ventas por sabor y producto, cuando dispongamos de esos datos.
6. **Informes:** evolución mensual, márgenes y gráficos sencillos.

Requisitos:
- Empieza con datos ficticios claramente identificados como demostración.
- Permite introducir y editar datos manualmente.
- Calcula correctamente los totales y distingue facturación, gastos y beneficio.
- No conectes todavía bancos, TPV ni sistemas contables.
- No inventes integraciones con Winex TPV4 ni Quantum.
- Organiza el código para que podamos añadir integraciones en el futuro.
- Incluye instrucciones sencillas para ejecutar el proyecto.
- Antes de hacer cambios importantes, explícame qué vas a modificar. Al terminar, indícame cómo probarlo.

Primero crea un prototipo funcional. Prioriza que los cálculos sean correctos, que los datos estén bien organizados y que la interfaz sea clara antes de añadir funcionalidades avanzadas de IA.
